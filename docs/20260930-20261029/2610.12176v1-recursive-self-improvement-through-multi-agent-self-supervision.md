## 摘要
模型在开放式研究等不可验证任务上的递归自我改进（RSI）面临监督瓶颈：当其输出超出连人类专家也无法可靠评估的范围时，模型自身（被优化对象）便成为最佳可用的优化器和评估器。然而，在这种同质循环中，单一模型实例难以批判并改进自身的复杂推理。为此，我们提出多智能体自我监督（MASS），一种在进化式工作流优化与基于自生成轨迹的监督微调之间交替的 RSI 方法。受多智能体拓扑在复杂推理方面表现优异的早期发现启发，MASS 促使单个基础模型迭代地提出、执行并自我评估多智能体工作流。通过受结构护栏约束的进化搜索，模型优化这些类似计算图的编排，为给定任务发现最有效的不同角色和信息路由。在使用 Qwen3.6-27B 的两个 MASS 周期中，该模型在四个开放式公开基准上实现了每个输出 token 性能提高 1.2–1.6 倍。由于改进后的模型随后充当更好的优化器和评估器，这种交替框架实现了模型能力的持续、递归自举。此外，多智能体轨迹在训练上也更高效：用其训练的学生模型优于用多 1.4 倍训练 token 训练的单智能体学生模型。这些发现表明，从多智能体轨迹中联合学习编排和有界子智能体执行，可以为 RSI 提供有效信号。

## Abstract
Recursive self-improvement (RSI) of a model on non-verifiable tasks, such as open-ended research, faces a supervision bottleneck when its outputs exceed what even human experts can reliably assess, leaving the model itself (optimizee) as the best available optimizer and evaluator. However, a single model instance struggles to critique and improve its own complex reasoning under this homogeneous loop. To address this, we propose Multi-Agent Self-Supervision (MASS), an RSI method that alternates between evolutionary workflow optimization and supervised fine-tuning on self-generated trajectories. Guided by early findings that multi-agent topologies excel at complex reasoning, MASS prompts a single base model to iteratively propose, execute, and self-evaluate multi-agent workflows. Through an evolutionary search constrained by structural guardrails, the model optimizes these computational-graph-like orchestrations, discovering the most effective distinct roles and information routing for a given task. Over two MASS cycles with Qwen3.6-27B, the model achieves 1.2-1.6x higher performance per output tokens on four open-ended public benchmarks. Because the improved model subsequently acts as a better optimizer and evaluator, this alternating framework enables a continuous, recursive bootstrapping of the model's capabilities. Moreover, multi-agent traces are also more training-efficient: a student trained on them outperforms a single-agent student trained on 1.4x more training tokens. These findings suggest that jointly learning orchestration and bounded subagent execution from multi-agent trajectories can provide an effective signal for RSI.

## 1. 核心问题与整体含义（研究动机与背景）

- **RSI 的两大瓶颈**：递归自我改进（Recursive Self-Improvement, RSI）由"评估"与"改进"两个环节驱动，但在开放研究等**不可验证任务**上二者同时受阻：
  - **评估端**：模型产出已超出人类专家可靠判断的范围，或反馈周期过长（如单次托卡马克等离子体研究需 >1.2 亿 CPU 小时）。
  - **改进端**：需要高质量执行数据来训练模型，而高质量数据又依赖更好的问题求解工作流；人工反复修改任务分解、工具调用与验证步骤成本过高。
- **同质自监督困境**：当最强模型同时充当求解者、工作流优化者与评估者时，生成、评估、修订共享同一学习先验，自反馈可能**强化而非纠正**错误，形成"同质循环"。
- **论文目标**：在"模型即最优监督者"的设定下，寻找一种能产生有用自监督信号的机制，使模型能力可持续递归自举。
- **核心洞察**：借鉴 Minsky《心智社会》，通过**重组模型的工作方式**（多智能体协作）而非仅生成更长推理链，来打破单一实例的盲区；并将协作经验蒸馏回共享权重。

## 2. 方法论：MASS（Multi-Agent Self-Supervision）

### 2.1 核心思想

- 用同一基座模型的多份副本组成多智能体系统，把**工作流（编排结构）编码为文本提示**附加到任务提示后，通过"进化式工作流优化 + 自生成轨迹监督微调"两个阶段交替，实现递归自举。
- 两条指导假设：
  - **H1（数据质量）**：优化智能体间"通信什么、向谁、何时"的信息流，可激发集体能力，提供不同于"更强推理链"的自监督。
  - **H2（学习效率）**：联合训练"编排"（委派、验证、整合）与"有界子智能体执行"两个抽象层级，比训练单智能体长程轨迹更高效（受分层模仿学习启发）。

### 2.2 关键技术细节

- **工作流表示**：对任务 \(t\)，工作流 \(w_t = \{h_t, (r_{t,j}, u_{t,j}, c_{t,j})_{j=1}^{m_t}\}\)，其中 \(r\) 为角色、\(u\) 为指令、\(c\) 为输出契约（子智能体返回给编排者的信息）、\(h\) 为子智能体调用顺序。编排者与所有子智能体共享同一模型。
- **内循环（算法 2：多智能体工作流优化）**：
  - 维护每任务的最优工作流 \(w^*_t\) 与历史反馈 \(D_t\)；执行 \(w^{(i)}_t\) 得输出 \(y^{(i)}_t\)，自评估器与 \(y^*_t\) 做成对比较并给出反馈 \(d_{t,i}\)；若更优则更新精英（精英规模为 1 的进化过程）。
  - 优化提示 \(x_{opt}\) **显式强调通信结构**（调用顺序 \(h_t\) 与输出契约 \(c_{t,j}\)）而非角色与指令，以聚焦信息流改进。
  - 所有提议均被执行（即使未替换精英），因此连续执行质量不保证单调上升。
- **外循环（算法 3：工作流内化 SFT）**：
  - 每任务用保留工作流独立执行 \(M=18\) 次，自评估器做成对锦标赛，**Bradley–Terry 模型**将成对判断转为工作区级分数并排序；前 \(K-1=15\) 条轨迹入训练集，第 \(K\) 条入验证集。
  - 构造数据时**移除工作流提示**，将编排者初始输入替换为裸任务（保留 worker 分配），迫使模型内化协调行为。
  - 按 ≤49,152 token 切窗（最多保留 8,192 token 上下文但掩码），仅对 assistant 目标计算损失：
    \[
    \ell_{SFT}(\theta) = -\mathbb{E}_{z\sim q}\left[\frac{\sum_{\ell=1}^{|z|}\mu_\ell \log p_\theta(z_\ell|z_{<\ell})}{\sum_{\ell=1}^{|z|}\mu_\ell}\right]
    \]
    其中 \(\mu_\ell=1\) 表示受监督的 assistant token，提示、工具输出与掩码上下文为 0。
  - 采用固定 **2:1 的子智能体/编排者窗口采样比**，以缓解子智能体窗口远多于编排者窗口的问题。
- **递归闭环（算法 1）**：第 \(g\) 代模型同时担任执行者、评估者、优化者；完成工作流搜索与 SFT 后得到 \(L^{(g+1)}\)，在下一代继续承担全部三个角色。
- **结构护栏**：工作流搜索受"通信结构优先"的优化提示约束；SFT 数据经自评估排序筛选；验证损失选 checkpoint。

## 3. 实验设计

### 3.1 模型、任务与基准

- **基座模型**：Qwen3.6-27B-FP8；编码智能体框架 qwen-code 0.20.0（全论文固定）。

- **公开基准（6 个）**：
  - 四个开放式研究基准：MLR-Bench（12 任务子集）、ScienceAgentBench（102 任务）、DSBench（74 任务）、AstaBench E2E-Bench-Hard（40 任务）。

### 3.2 训练配置

- 119 条教师轨迹（8 任务 ×15，剔除 1 条提前终止），产出 **2,435 个窗口**（282 编排、2,054 子智能体、99 辅助），**17.2M 监督 token**。
- LoRA：rank 64、scaling 128、dropout 0.05；AdamW（β1=0.9, β2=0.95），峰值学习率 3e-5，5 步 warmup，余弦衰减至 10%；**1,624 步 × 3 窗口/步**；按验证损失选 checkpoint（第一轮用 step 1200）。

### 3.3 对比与消融

- **主对比**：\(L^{(0)}\)（基座）vs \(L^{(1)}\) vs \(L^{(2)}\)，覆盖任务求解、工作流优化、评估三种角色。
