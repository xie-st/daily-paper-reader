## 摘要
智能体可以通过改变其行动方式以及保留哪些经验，在未解决的问题中改进自身行为。我们提出MMLA-RSI，这是一种递归自我改进方案，并在记忆中介学习架构中给出两种实现：推理时训练（RTT）改变策略状态 Φ，而推理时记忆适配（RTMA）改变权威记忆 M。每条路径还将其适配方法本身作为改进对象。当前的数值更新器训练策略，由该策略提出其继任者；当前的记忆管理器选择可供提出其继任者的过程使用的记录。独立获准的继任者在下一代中接管同一角色。我们给出有界可执行规则语言、共享任务/提议接口，以及一种适用于任一途径或二者组合的算法。RTT实例在裁剪动量更新中改变标量调度。RTMA实例选择NULL或可能伴随驱逐的完整行写入。固定解释器、可信提交器和独立评估器限定可改变的内容。状态版本、读闭包和条件属性描述因果执行、被接受的转换以及有限工作量。现有数值组件研究为这一构造提供了动机。在四候选程序选择中，保留LARC反馈更新使两个训练初始化的期望误差分别降低24.65和36.65个百分点。在按时间顺序的持续集成回放中，反馈绑定为正向，而保留会增加损失。已完成的SQL研究相较于未适配基底有显著改进，但并未确立所需的额外在线收益。这些结果刻画了其声明的组件。本文给出了两条递归途径及其联合实现；其有益的递归链与发现效率仍有待评估。

## Abstract
An agent can improve its behavior within an unresolved problem by changing how it acts and which experience it retains. We propose MMLA-RSI, a recursive self-improvement scheme with two implementations in Memory-Mediated Learning Architecture: Reasoning-Time Training (RTT) changes the policy state $Φ$, while Reasoning-Time Memory Adaptation (RTMA) changes authoritative memory $M$. Each route also makes its adaptation method an object of improvement. A current numerical updater trains the policy proposing its successor; a current memory manager chooses the records available to the process proposing its successor. An independently admitted successor takes over the same role in the next generation. We give bounded executable rule languages, shared task/proposal interfaces, and one algorithm for either route or their composition. The RTT instance changes scalar schedules in a clipped-momentum update. The RTMA instance chooses NULL or a complete-row write with possible eviction. A fixed interpreter, trusted committer, and independent evaluator bound what can change. State versions, read closures, and conditional properties describe causal execution, accepted transitions, and finite work. Existing numerical-component studies motivate the construction. In four-candidate program selection, retaining LARC feedback updates reduces expected error by 24.65 and 36.65 percentage points for two trained initializations. In chronological continuous-integration replay, feedback binding is positive while retention increases loss. Completed SQL studies improve substantially over an unadapted substrate but do not establish the required additional online benefit. These results characterize their declared components. The two recursive routes and their joint realization are specified here; their beneficial recursive chains and discovery efficiency remain to be evaluated.

## 2. 方法论

### 2.1 核心思想

- 在 MMLA 中区分两个学习对象：
  - **策略状态 Φ**：由 RTT 在问题未解决时通过数值更新改变。
  - **权威记忆 M**：由 RTMA 通过可信提交改变，后续尝试读取其版本。
- 递归层：当前规则 η_k 不只是被使用，还参与“提出继任规则 η_{k+1}”的过程：
  - RTT：当前数值更新器 U_η 更新提案策略状态，使该策略生成下一更新器候选。
  - RTMA：当前记忆管理器 V_η 选择提案过程可读的评估记录，使该过程生成下一管理器候选。
- 继任者必须经过独立审计和采纳，然后在下一代中接管同一角色；提案状态每代重置，但规则版本延续。

### 2.2 关键技术细节

- **时间与因果条件**：一次尝试结束 ε_j、反馈可见 v_j、更新提交 u_j、下一次新提案开始 σ_{j+1}、问题解决 τ，要求 ε_j ≤ v_j ≤ u_j < σ_{j+1} < τ。即反馈必须在更新前到达，更新必须在下一次读取前提交，且都发生在问题解决前。
- **读闭包**：控制实验必须声明所有可能影响后续动作的依赖，包括上下文、缓存、优化器状态、随机数状态、回调等；仅从提示中删除反馈不足以构成干净干预。
- **功能使用判据**：功能使用不等于任务收益。论文用动作核的总变差距离 TV > 0 描述功能依赖，并强调固定随机带的回放差异不自动证明边际动作分布差异。
- **RTT 有界语言**：在固定 clipped-momentum 模板中，用三棵标量表达式树分别产生步长 a、裁剪阈值 κ、动量 μ；语法含有限常量、加减乘、min/max、安全除法，限制节点数、深度和序列化长度；解释器、数值实现、投影和失败回滚固定。非有限中间值、非法树、超指令上限等会拒绝整次更新并恢复 Φ 与私有状态。
- **RTMA 有界语言**：记忆管理器是一棵标量表达式树，对 NULL 或 WRITE_i 的动作特征评分并取 argmax；特征包括是否 NULL、占用、新旧记录损失/成本、年龄、占用率等。非 NULL 动作写入一条完整行，可能驱逐旧行；可信提交器检查类型、来源、容量、前驱版本和 epoch。NULL 为显式 no-op。
- **联合实例**：候选为规则对 (η_Φ, η_M)；同一到达反馈先执行 RTT 数值更新，再执行 RTMA 记忆提交；各载体操作原子，但规则对不是单一事务；失败时保留已成功提交并记录收据。

### 2.3 算法流程

- 每代绑定父规则 η_k，重置提案状态 Φ_prop=ρ_prop、M_prop=M_prop0。
- 采样至多 N 个有界候选规则；合法候选在开发任务上执行，得到平均损失和归一化成本，形成奖励。
- 若还有下一次提案，调用**父规则**（而非候选）更新提案状态或提案记忆，然后生成下一次尝试。
- 有限提案预算后锁定一个候选；候选与父规则在成对、未使用过的审计任务上比较。
- 采纳条件为审计上界满足 U_k(η') + δ ≤ L_k(η_k)，并通过确定性资源检查；否则保留父规则并终止或按合同结束。
- 下一代重置提案状态，但使用被采纳的新规则。有限递归链要求：父规则功能性参与生成子规则、每条边有独立改进证据、且被采纳的 η_1 实际参与生成 η_2。

### 2.4 条件性质

- **因果组合**：在 epoch 约束和审计锁定顺序下，有限代序列中的动作对当时可用信息可测。
- **有限采纳**：若审计区间同时覆盖风险，且每条被接受边至少降低 δ 风险，则接受边数至多 floor(R(η_0)/δ)。
- **有限工作**：代数、提案数、指令数、状态大小和资源预留均有界，总工作量受预留成本之和约束。
