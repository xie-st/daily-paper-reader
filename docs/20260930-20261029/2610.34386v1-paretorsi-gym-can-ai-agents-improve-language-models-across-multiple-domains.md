## 摘要
递归自我改进（RSI）要求一个智能体系统能够设计、训练并评估其自身的后继者。数据驱动的后训练是该循环的核心部分，但现有评估仅在单一基准上衡量它：智能体从静态池中选择数据，或蒸馏一个更强的模型，以在一次运行中推高单一分数。真实的后训练是多领域的，一个领域的收益必须与另一个领域的退步权衡。我们提出 ParetoRSI-Gym，其中智能体搜索数据、筛选数据、训练、回读各领域结果并重复，除数据外其余均保持固定：初始 LLM、五个领域（数学、代码、金融、医学、科学）、工具集以及 SFT 流水线。每个领域的泛化基准将能力提升与对智能体所优化分数的过拟合区分开来。在三种智能体系统、三个基础模型、五轮和多个随机种子下，最强的系统 Claude Code 搭配 Opus-5，将其代理最优检查点的泛化分数相对于起始模型提高了 9.2%（+2.3 绝对点），这是在三个基础模型和五个领域上等权平均的结果，单领域相对增益最高达 63%（Ministral-3-3B 上的医学）。进一步分析表明，运行框架与其驱动的模型同样重要，并且每个智能体都保持独特的数据选择策略。我们将自己的工作视为迈向在真实机器学习工程中评估 RSI 系统的一步。

## Abstract
Recursive self-improvement (RSI) requires an agentic system to design, train, and evaluate its own successor. Data-driven post-training is a central part of that loop, yet existing evaluations measure it on a single benchmark, where an agent selects from a static pool or distills a stronger model to push one score up in one run. Real post-training is multi-domain, and a gain in one domain has to be weighed against a regression in another. We propose ParetoRSI-Gym, in which an agent searches for data, curates it, trains, reads back per-domain results, and repeats, with everything but the data held fixed: the initial LLM, the five domains (math, code, finance, medicine, science), the toolset, and the SFT pipeline. Generalization benchmarks in each domain separate capability gains from overfitting to the scores the agent optimizes against. Across three agent systems, three base models, five rounds and multiple seeds, the strongest system, Claude Code with Opus-5, raises the generalization scores of its proxy-best checkpoint by 9.2% relative to the starting model (+2.3 absolute points), averaged with equal weight over three base models and five domains, with a single-domain relative gain of up to 63% (medicine on Ministral-3-3B). Further analysis shows that the harness matters as much as the model it drives, and that each agent keeps a unique data selection strategy. We see our work as a step towards evaluation of RSI systems in real-world machine learning engineering.

- **核心问题**：LLM 智能体能否在**多个能力维度上同时**改进模型，并在**反复轮次**的策展循环中持续改进？这正是论文标题所问的。
- **整体含义**：论文把 RSI 评测从“单分数刷榜”推进到“多领域 Pareto 前沿 + 留出泛化”的真实 ML 工程场景，为自动化后训练研究提供一个更贴近实际、可抗奖励黑客（reward hacking）的测试平台。

## 2. 方法论

### 2.1 核心思想
- 构建一个**固定其余变量、只放开数据**的迭代策展循环：初始 LLM、五个领域、工具集、SFT 流水线全部冻结，智能体唯一能改变的是**选什么数据、怎么配训练超参、从哪个检查点继续**。
- 优化目标不是单一分数，而是**五维能力向量的 Pareto 前沿**相对于初始模型 M₀ 的推进。

### 2.2 关键设计原则（五项）
- **跨轮状态（Cross-round state）**：模型池 M、数据池 P、书面原则 R 跨轮持久，第 t 轮的提交约束第 t+1 轮。
- **动态数据源**：数据在运行时从 HuggingFace Hub 现场搜索、拉取，而非预先组装好的静态池。
- **反馈驱动修订**：每轮回传分领域代理分数，甚至逐条生成结果（per-item trace），智能体据此重写原则。
- **多域目标**：每轮看到完整分数向量与非支配检查点集合，被要求推进前沿而非任一坐标。
- **泛化评估**：最终分数来自智能体**从未见过**的留出基准，以区分真实能力提升与对反馈的过拟合。

### 2.3 循环流程（Algorithm 1 文字化）
1. 初始化：`M ← {M₀}`，数据池 `P ← ∅`，`s₀ ← T_proxy(M₀)`，智能体据 `s₀` 写出初始原则 `R₀`。
2. 对每轮 `t = 1…T`：
   - **ACQUIRE**：依 `R_{t-1}` 在 Hub 上执行 SEARCH / SELECT / PULL，新条目并入 P（只增不减，保留来源与提交理由）。
   - **COMMIT**：在预算 β 内选定父检查点 `M_par`、训练集 `D_t`、训练配置 `C_t`。
   - **训练**：`M_t ← S(M_par, D_t; C_t)`，`M ← M ∪ {M_t}`。
   - **评估**：`s_t, E_t ← T_proxy(M_t)`，返回分数向量与逐条结果。
   - **修订**：`R_t ← A(R_{t-1}, s_{0:t}, E_t)`，原则在同一预算下重写。
3. 结束后一次性在留出集上评分：报告最终轮 `T_general(M_T)` 与**代理最优轮** `T_general(M_{t*})`，其中 `t* = argmax_t mean(s_t)`。

### 2.4 训练与数据约束细节
- 固定 **LoRA SFT + AdamW**，1 个 epoch；智能体只能在给定范围内选择 `lr`、`lora_rank`、`batch_size`、`max_len`、`warmup_steps`。
- 每轮上限 **1500 万训练 token / 4 万条数据**；一次运行 **5 轮**。
- 训练沿所选检查点的**谱系累积**，回退只能通过“从更早检查点分叉”实现，且会丢弃后续所学。
- 所有入库数据需通过 **13-gram 去污染**检查（针对全部代理与留出题项），命中即拒。
- 书面原则（skill 文件）预算 **8000 token**，每条须标注依据（prior / `rN:axis±points` / retired），且引用分数会被 harness 校验，不符则整轮拒绝。
