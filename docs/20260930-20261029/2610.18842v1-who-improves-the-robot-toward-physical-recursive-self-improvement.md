## 摘要
机器人在任务执行上日益自主，但其改进仍主要依赖人类驱动。本研究探讨物理递归自我改进（Physical RSI），其中物理经验引导对机器人能力及其改进程序的持久更新，使后续改进在跨任务上更有效。Physical RSI 面临来自噪声观测、连续动力学、高成本试验以及不可逆后果的挑战。我们提出一个 L0-L5 框架，区分能力层面与元层面的更新，以及任务内与跨任务的收益，并将 L5 保留给经独立验证的递归收益。我们研究围绕执行框架适配与模型训练的现有方法，以及约束执行与后续更新的安全与控制机制。我们的分析表明，尽管在自我改进方面已取得显著进展，但所综述的文献尚未证明符合我们框架定义的 Physical RSI。我们明确了可靠反馈、因果归因、安全保持与基准测试方面的研究优先事项，并勾勒出一条通向机器人能够在确保安全的同时自主改进其学习方式的路径。Physical RSI 的 GitHub 仓库见 https://github.com/SAIL-Research-Lab/Physical-RSI。

## Abstract
Robots are increasingly autonomous in task execution, yet their improvement remains largely human-driven. This study investigates Physical Recursive Self-Improvement (Physical RSI), in which physical experience guides lasting updates to both a robot's capabilities and its improvement procedure, making subsequent improvement more effective across tasks. Physical RSI faces challenges from noisy observations, continuous dynamics, costly trials, and irreversible consequences. We present an L0-L5 framework that differentiates capability-level from meta-level updates and within-task from across-task gains, reserving L5 for independently verified recursive gain. We study existing methods around harness adaptation and model training, alongside safety and control mechanisms that govern execution and successive updates. Our analysis reveals that, despite substantial progress in self-improvement, the surveyed literature does not yet demonstrate Physical RSI as defined by our framework. We identify research priorities in reliable feedback, causal attribution, safety preservation, and benchmarking, outlining a path toward robots that autonomously improve how they learn while ensuring safety. The GitHub repository for Physical RSI is available at https://github.com/SAIL-Research-Lab/Physical-RSI.

## 一、核心问题与研究动机

- **现实矛盾**：机器人在*任务执行*上已高度自主（物流分拣、家务操作），但在*自我改进*上仍高度依赖人类——数据由人采集与审核、故障由人诊断与示范修复、训练流程由人设计、最终采纳哪次更新也由人拍板。作者称这种能力为“改进自主性（improvement autonomy）”的缺失。
- **现有工作的局限**：当前“自我改进”研究（LLM agent 改写代码/脚手架、模型自训练）大多只提升**任务执行系统**，而产生与筛选这些改动的**改进程序本身保持固定**，因此收益上限被该程序的有效性锁死。
- **递归自我改进（RSI）的严格含义**：不仅要改“做什么”，还要改“怎么改进”；只有当**更新后的改进程序在同等条件下比前一版产生更好的后续改进**时，才算确立“递归收益（recursive gain）”。这样的工作极少，能证明递归收益的更少。
- **物理世界的额外困难**（作者列为四条，构成本文立论基础）：
  1. 连续、实时的动力学交互，任务必须物理完成，不能暂停/回放；
  2. 试错成本高且部分动作**不可逆**，重置昂贵、硬件会损坏；
  3. 观测**局部且含噪**，失败难以归因，仿真证据存在 sim-to-real 落差；
  4. 机器人与人共处，需安全约束与人类监督兜底。
- **因此**：不能把数字环境中的 RSI 框架直接搬到机器人上，需要一套**物理接地（physically grounded）**的独立框架。论文的长期愿景是：机器人在真实物理环境中自主运行与演化，无需人工介入即可应对未见挑战。

## 二、方法论：核心思想与框架细节

### 2.1 系统形式化：把“机器人”拆成四元组

- **任务执行系统** $M=(\Theta, H)$
  - **Harness $H$**：模型之外的部分——prompt、记忆、技能/工具库、任务分解与恢复逻辑、接口与控制器代码。
  - **参数模型 $\Theta$**：执行期使用的学习模型权重——规划器、VLA 策略、价值函数、世界模型。
- **改进程序** $\Phi=(\text{Adapt}, \text{Train}, \text{Ver})$
  - `Adapt` 更新 $H$；`Train` 选择经验并优化 $\Theta$；`Ver` 判定候选改动是否保留。
  - $\Phi$ 可自我修改：对 Adapt/Train 的改动由 `Ver` 裁决，对 `Ver` 的改动由**外部独立评估器 $E$** 裁决。
- **经验与反馈存储 $D$**：执行记录 + 改进记录（改了什么、如何被判定）。
- **独立评估器 $E$ 与评分准则 $Q$**：$\Phi$ 不可读、不可训练、不可修改；用于给 $(\Theta_k,H_k)$ 打分 $J_Q(\Theta_k,H_k)$，并裁决对 `Ver` 的修改。$E$ 随新任务扩展时，需重评历史代或在固定锚点子集上比较。

### 2.2 关键概念：物理接地与继承

- **物理接地**：改动必须依赖“机器人实际动作后发生了什么”。可接受的来源是**真实世界或物理仿真器**；学习到的世界模型、人类、内部信号只能提候选或补数据，**单独不构成物理接地**。
- **继承（inheritance）**：改动被 $\Phi$ 依据 $D$ 中的证据保留，并跨越产生它的 episode 持续存在，成为后续代的起点。
- **代际递推式**（核心公式）：
  $$S_k=(\Theta_k,H_k,\Phi_k,D_k),\quad \Phi_k=(\text{Adapt}_k,\text{Train}_k,\text{Ver}_k)$$
  $$(\Theta_{k+1},H_{k+1},\Phi_{k+1})=\Phi_k\big(\Theta_k,H_k,\Phi_k;\,D_{k+1}\big)$$
  注意 $\Phi_k$ 出现在**自身参数位**上，这是“递归”的形式化体现；也正因此，对 `Ver` 的修改不能由 `Ver` 自评，必须引入外部 $E$。

### 2.3 两个定义（判定标准）

- **定义 1：物理自我改进（Physical Self-Improvement）**——需同时满足：
  - (i) *能力级自继承*：$\Theta$ 或 $H$ 至少有一处改动由 $\Phi$ 产生并被继承，且**无人类写入** $\Theta/H/\Phi$；
  - (ii) *物理接地*：所依赖的继承改动有物理依据；
  - (iii) *保留收益*：$J_Q(\Theta_K,H_K)>J_Q(\Theta_0,H_0)$。
- **定义 2：物理递归自我改进（Physical RSI）**——在定义 1 基础上强化：
  - (i) *元级自继承*：$\Phi$ 能更新自身各阶段，且改动可被后续轮次继承使用；
  - (ii) *物理接地*（同上）；
  - (iii) *跨任务递归收益*：**从同一代、同一经验、同一预算出发**，被更新后的 $\Phi_k$ 产出的系统 $J_Q$ 高于 $\Phi_{k-1}$ 产出的系统，且收益跨任务度量。

### 2.4 三个循环与两条路径

| 循环 | 使用 | 写入 | 效应可见于 |
|---|---|---|---|
| 执行循环 | $H,\Theta$ | $D$ | 当前 episode（**不算改进**） |
| 能力级更新循环 | $\Phi$ 各阶段 | $H,\Theta,D$ | 后续任务 |
| 元级更新循环 | $H,\Theta$ | $\text{Adapt},\text{Train},\text{Ver},D$ | 后续轮次的改动方式 |

- **Harness 路径（$H$ + Adapt）**：反馈解释与更新目标识别 → 记忆/技能/工作流适配 → 采纳与改进历史 → 对 Adapt 本身的元改进。
- **训练路径（$\Theta$ + Train）**：数据准备（经验生成与筛选）→ 训练方法（IL / SSL / RL）→ 学习模型（VLA、世界模型、奖励模型）→ 知识迁移与训练流程改进。
- 两条路径**相互作用**：加入 $H$ 的技能改变进入 $D$ 的轨迹分布；更新后的 $\Theta$ 改变哪些 harness 编辑值得提出。

### 2.5 L0–L5 分级框架（核心贡献）

- **两个正交判据**：①更新对象（能力级 vs 元级）；②作用范围（同一任务 vs 跨任务）。
- **任务同一性判据**：任务由**技能序列 $\kappa$** 刻画；**实例参数 $\xi$**（物体位姿、布局、难度）变化不算换任务。$\kappa$ 改变的两种方式：**新增技能**，或**已有技能的新组合/新顺序**（长程任务典型形态）。
- **等级划分**：
  - **L0**：无自主保留改动（仅 run 内调整，或人类主导回路；含“依赖人类标注/介入”的系统，作为参照组）。
  - **L1**：单任务、能力级更新（$\Phi$ 冻结）。
  - **L2**：单任务、元级更新。
  - **L3**：跨任务、能力级更新。
  - **L4**：跨任务、元级更新。
  - **L5**：L4 + 由独立评估器在受控条件下证明**每一轮更新都比上一轮带来更大收益**。
- **判定四问**：$\Phi$ 是否产生保留改动 → 改的是 $H/\Theta$ 还是 $\Phi$ → 收益是同任务还是跨任务（按 $\kappa$ 判）→ 是否确有 $J_Q$ 提升。
- **证据来源标注**：R（真实）/ S（仿真）/ O（模型想象），并区分“反馈来源”与“部署场景”（如 S→R† 表示仿真反馈驱动更新后部署到真机）。

### 2.6 安全与控制（贯穿三循环，而非事后检查）

- **受保护约束（protected constraints）**：安全规则与 $E$、$Q$ 一起置于 $\Phi$ 触及范围之外——因为被更新的 `Ver` 可能自行放宽检验标准。
- 五个层面：安全探索与持续适应（约束 MDP、CPO、SafeVLA、SCDA、GP 安全区域、稳定性证书）→ 安全迁移与更新接受（Sim-to-Lab-to-Real、鲁棒安全迁移、High Confidence Policy Improvement、Seldonian 框架）→ 环境漂移下的运行时保障（CBF、动作滤波器、可达性、预测型安全滤波、shield、故障检测与恢复）→ 对演化中改进程序的监督（保证明的模型/控制器更新、防止 `Ver` 漂移、防提示注入、人类介入须与自主性分级分开记录）→ 跨代安全证据（**并集界** $\Pr(\bigcup_{k=1}^{K}V_k)\le\sum_{k=1}^{K}\delta_k$；区分“误接受更新”与“物理伤害”；重复选择需统计误差控制）。
- **接受 ≠ 放行**：`Acceptance` 决定是否继承，`Release` 是允许在特定条件下物理运行的独立授权；在 $E$ 上得分提高本身**不构成**放行证据。

### 2.7 验证与评估

- **`Ver` 内部验证**四项：实现有效性（语法/接口/格式）、修复有效性（在失败用例上重执行、与旧版对比）、能力保持（回归测试旧任务、暂停依赖已变身体估计的规则）、元验证（`Ver` 自身被改时，须比较原/新验证器所产出系统的后续表现）。
- **独立评估**三项：性能与保持（前后对比、多轮 checkpoint、用未参与调试的初始条件评估）、归因与迁移（匹配轨迹数/初始数据/架构/配方的受控比较、消融、库快照对比、跨具身测试）、效率与自主性（机器人/GPU 利用率、token 消耗、达成功耗时；显式关闭人类纠正与接管）。
