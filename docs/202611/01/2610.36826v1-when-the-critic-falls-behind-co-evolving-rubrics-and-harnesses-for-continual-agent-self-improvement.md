## 摘要
自主智能体日益依赖围绕大语言模型（LLM）来管理交互、记忆、工具与执行的执行框架。尽管近期工作已开始基于执行经验演化这些执行框架，但用于指导演化的监督信号往往相对静态，难以跟踪不同轮次中不断变化的行为弱点，并可能限制对未见任务的泛化能力。为解决该问题，我们提出 RuHarness，一个面向智能体持续自我改进的评分标准—执行框架协同演化框架。RuHarness 从执行轨迹中持续发现并重新评估行为准则，优先处理最相关的未解决弱点，并利用这些弱点指导有针对性的执行框架更新，同时保持任务目标固定。在多样化的智能体任务和骨干模型上进行的大量实验表明，RuHarness 优于强执行框架演化基线，尤其是在未见的留出任务上。进一步分析表明，自适应评分标准优先级排序能够跟踪不断变化的弱点，并在多轮演化中支持更持续的改进和稳定的泛化。

## Abstract
Autonomous agents increasingly depend on harnesses that govern interaction, memory, tools, and execution around large language models (LLMs). While recent work has begun to evolve these harnesses from execution experience, the supervision used to guide evolution often remains relatively static, making it difficult to track changing behavioral weaknesses across rounds and potentially limiting generalization to unseen tasks. To address this issue, we propose RuHarness, a rubric--harness co-evolution framework for continual agent self-improvement. RuHarness continually discovers and reassesses behavioral criteria from execution trajectories, prioritizes the most relevant unresolved weaknesses, and uses them to guide targeted harness updates while keeping the task objective fixed. Extensive experiments across diverse agent tasks and backbone models show that RuHarness outperforms strong harness-evolution baselines, particularly on unseen held-out tasks. Further analyses show that adaptive rubric prioritization tracks shifting weaknesses and supports more sustained improvement and stable generalization across evolution rounds.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：自主智能体的性能不仅取决于底层 LLM 的能力，也取决于围绕模型管理交互、记忆、工具与执行的 **harness（执行框架）**。近期研究已开始从执行经验中演化 harness，使智能体无需更新模型参数即可改进。
- **核心问题**：指导 harness 演化的监督信号通常**相对静态**（如任务级成败反馈），存在两个关键缺陷：
  - **行为诊断粒度粗**：任务级反馈只说明“是否成功”，难以揭示失败背后的行为缺陷；
  - **弱点会漂移**：随着 harness 改进，原先主导的失败被缓解，新的、更细微的失败模式浮现。静态评分标准（rubric）会逐渐“落后”（critic falls behind），失去区分度与指导价值，甚至误导优化方向。
- **后果**：重复的 harness 优化可能过拟合于演化过程中暴露的任务特定失败模式，导致**对未见任务的泛化能力下降**（近期受控评估已提示此风险）。
- **整体含义**：持续 harness 演化需要**自适应诊断机制**——在保持任务目标固定的前提下，持续重新评估并重新排序行为弱点，使监督信号随智能体行为共同演化。

## 二、方法论：RuHarness 框架

### 2.1 核心思想

- 建立 **rubric 与 harness 的协同演化闭环**：harness 塑造当前暴露的行为弱点，rubric 决定哪些弱点被优先处理并指导下一轮 harness 更新。
- 系统状态：\( S_t = (H_t, R_t) \)，交替执行：
  - **Rubric 演化**：\( R_{t+1} = E_R(R_t, T_t) \)
  - **Harness 演化**：\( H_{t+1} = E_H(H_t, \hat{R}_{t+1}) \)
- 每轮在当前 harness 上运行演化任务集 \( D_{evo} \) 收集轨迹 \( T_t \)，形成闭环。

### 2.2 Rubric 演化：适应漂移的行为弱点

- **失败报告结构化**：将每个失败轨迹总结为结构化报告（目标、最终状态、分歧步骤、逐字证据、失败模式、是否可归因、错失机会），再跨任务聚合为反复出现的行为模式，转化为新准则。
- **结果盲评（Outcome-blind Judging）**：对每条轨迹 × 每条准则，评判器仅基于轨迹中的**行为证据**给出 `Satisfied / Violated / N/A`，**屏蔽最终任务结果**，防止成功/失败标签泄漏。
- **准则准入（Birth Check）**：拒绝三类无效准则——(i) 超过 80% 为 N/A（从不适用）；(ii) 在失败轨迹上从不触发；(iii) 整体触发率 >90% 且成功轨迹上也 >90%（无区分度）。
- **四状态生命周期**：`probation → active → dormant → retired`，依据触发率、预测效度、N/A 漂移等条件转移（如 active 连续 3 轮触发率 <5% 转 dormant；dormant 触发率 ≥15% 可复活；持续无信息则退休）。仅 active 准则参与后续排序。
- **时变诊断效用**：
  \[
  U_{t+1}(c) = \alpha D + \beta C + \gamma P + \delta N - \lambda Red
  \]
  - \( D \)：区分度（失败 vs 成功轨迹的违反率差）；
  - \( C \)：覆盖率（准则捕获的失败轨迹比例）；
  - \( P \)：预测效度（违反时失败概率相对基线的提升）；
  - \( N \)：新颖性（仅被该准则识别的失败轨迹比例）；
  - \( Red \)：与现有准则的最大 Jaccard 重叠（冗余惩罚）。
- **保守后验排序（Adaptive Rubric Frontier）**：
  - 对 2×3 列联表（结果 × 评判）加 Jeffreys 先验（每格 +0.5），得 Dirichlet 后验；
  - 采样 \( B=2000 \) 次重算 \( D, C, P \)（\( N, Red \) 固定）；
  - 取效用分布的 **q=0.2 下分位数** \( \tilde{U}(c) \) 作为保守评分，抑制小样本高估；
  - 选 Top-K（K=10）活跃准则构成 **rubric frontier**。

### 2.3 Harness 演化：面向移动前沿的优化

- **六功能坐标抽象**：`Equip`（技能/工具）、`Instruct`（提示/指令）、`Act`（动作策略）、`Observe`（观测处理）、`Remember`（记忆/上下文）、`Terminate`（终止控制）。
- **前沿引导的定向映射**：每条优先准则可映射到一个或多个坐标（非一对一），允许多坐标联合干预。
- **协调候选生成**：每轮生成至多 3 个候选，每个候选是最多 3 个坐标修改的**协调集合** \( \Delta_j = \{\delta_j^{(k)}\}_{k \in M_j} \)，应用 \( H_t^{(j)} = H_t \oplus \Delta_j \)；候选需通过轻量验证器（只接受/拒绝，不重写、不估分）。
- **验证门控更新**：在独立验证集 \( D_{val} \) 上评估候选，选择最优者 \( H_t^\star \)；仅当提升超过阈值 \( \epsilon = 0.05 \) 才提交：
  \[
  H_{t+1} = \begin{cases} H_t^\star, & S(H_t^\star, D_{val}) - S(H_t, D_{val}) > \epsilon \\ H_t, & \text{otherwise} \end{cases}
  \]
- **超参数**：\( \alpha=\gamma=1.0 \)，\( \beta=\delta=\lambda=0.5 \)，\( q=0.2 \)，\( K=10 \)，每候选最多改 3 个组件。

  - **w/o Rubric Module**（退回任务级成败反馈）降幅最大，说明细粒度行为诊断是收益的主要来源；
  - **w/o Rubric Evolution**（固定初始 rubric）次之，验证了静态评分标准会随 harness 改进而“落后”，导致后期优化方向失准；
  - **w/o Rubric Frontier**（用完整排序池替代保守 Top-K）亦有下降，说明**小样本下的乐观偏置**确实会误导准则选择，保守后验下分位数排序具有实际价值。
  - 三个组件呈**递进式贡献**：诊断粒度 → 诊断时效性 → 诊断可靠性。
- **Rubric 动态**：与初始前沿 \(F_0\) 的 Jaccard 相似度随轮次持续下降，而与相邻轮 \(F_{t-1}\) 保持较高相似度，呈“**缓慢漂移而非剧烈跳变**”的模式——说明准则更新是渐进的、由证据驱动的，而非随机震荡。
- **前沿转移分析**：准则进入前沿时，其区分度、覆盖率、预测效度与新颖性普遍高于池内平均；退出前沿的准则多因触发率衰减（弱点已被缓解）或冗余度上升。这直接印证了“**弱点会漂移**”的核心假设。
- **行为缓解分析**：准则进入前沿后，对应行为的违反率显著下降；且在**提交了 harness 更新**的轮次中下降幅度明显大于未提交轮次，构成“准则 → harness 修改 → 行为改变”的因果链证据。
- **泛化差距与前沿覆盖率**：动态 rubric 在保持较高前沿覆盖率的同时，泛化差距（held-in 与 held-out 之差）小于静态 rubric，说明持续重排弱点有助于抑制对演化任务特定失败模式的过拟合。
- **前沿诊断价值分布**：前沿内准则的效用分布显著右移于全池分布，验证 Top-K 选择的有效性；但分布存在重叠，提示 K 的取值仍是可调权衡（更大 K 带来覆盖但引入噪声）。
- **鲁棒性**：3 个随机种子的均值 ± 标准差表明方法优势在种子间稳定，未出现某一seed驱动的偶然结果。
- **案例研究**：知识工作与信息检索两条轨迹展示了不同的演化路径——前者主要围绕“观测筛选与中间产物组织”迭代，后者围绕“检索查询构造与终止判断”迭代，说明同一框架能针对不同领域自动发现**领域特异的**行为弱点，而非套用统一模板。

## 七、局限与未来工作

- **算力与规模限制**：受计算资源约束，实验固定为 10 轮演化、有限任务规模，未探索更长演化周期下的收敛性、准则池饱和或退化风险。
- **环境封闭性**：仅在 EvoAgentBench 的五个基准衍生域上评估，未涉及开放式、真实交互环境（如真实网页、真实代码库长期协作），外部效度有待检验。
- **监督信号仍依赖结果标签**：结果盲评虽屏蔽了最终成败，但失败报告的生成与“是否可归因”的判断仍由 LLM 完成，可能引入评判器自身偏差；未报告评判器与人类判断的一致性。
- **超参数未系统调优**：效用权重 \( \alpha,\beta,\gamma,\delta,\lambda \)、分位数 \( q \)、前沿规模 \( K \)、提交阈值 \( \epsilon \) 均取固定值，缺乏敏感性分析。
- **统计严谨性**：未报告显著性检验或置信区间（除种子实验外），部分单域差异可能落在噪声范围内。
- **成本结构未量化**：每轮需运行演化集、逐轨迹 × 逐准则评判、生成并验证多候选，推理调用量显著高于基线，但论文未给出 token/调用成本对比，难以评估性价比。
- **未来方向**（据论文定位推断）：更长周期的演化稳定性、跨模型/跨框架的迁移性、评判器校准与人类对齐、成本感知的准则筛选、以及与参数级更新（微调）的互补结合。

## 八、贡献与启示

- **问题界定上的贡献**：将“监督信号静态化”明确为一个**随时间恶化**的问题（critic falls behind），而非一次性的设计缺陷，为自我演化智能体研究提供了新的分析视角。
- **方法上的贡献**：提出 rubric–harness **协同演化闭环**，并用一套可操作的工程机制（结构化失败报告、结果盲评、准入检查、四状态生命周期、保守后验排序、六坐标定向映射、验证门控提交）将其落地；其中**结果盲评**与**保守后验排序**是抑制监督信号偏差的两个关键设计。
- **实证上的贡献**：在统一数据划分、统一初始 harness、统一候选预算的受控条件下，跨 2 个骨干模型、5 个领域、6 个基线验证了方法有效性，并通过消融与机制分析（前沿转移、行为缓解、泛化差距）提供了**过程性证据**，而非仅报告终点指标。
- **实践启示**：
  - 对智能体系统的工程迭代而言，**“评估什么”本身需要被迭代**；固定的评估清单在长期优化中会失效。
  - 细粒度、可归因的行为准则比任务级成败信号更具指导价值，但需要配套的**准入与退役机制**防止准则池膨胀与噪声累积。
  - 在候选修改上采用**多坐标协调 + 独立验证门控 + 提升阈值**，是控制演化方差、避免“为改而改”的有效手段。

## 九、总体评价

论文问题意识清晰，将“评分标准滞后”这一常被忽视的现象提炼为核心矛盾，并给出结构完整、机制可解释的解决方案。实验设计在受控性（统一划分/预算/初始状态）与证据层次（主结果 + 消融 + 过程分析 + 案例）上均较为扎实，尤其“行为缓解分析”为因果链提供了直接支撑。主要不足在于算力与成本透明度低、超参数与统计检验缺失、评估环境仍局限于基准衍生任务。总体而言，这是一篇**机制贡献大于规模贡献**的工作，其“让监督信号与智能体共同演化”的思路对自我改进型智能体研究具有较好的启发性与可复用性。
