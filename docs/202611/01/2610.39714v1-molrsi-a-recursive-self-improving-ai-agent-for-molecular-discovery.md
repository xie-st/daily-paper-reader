## 摘要
分子发现需要在庞大的组合搜索空间中进行探索，同时平衡相互竞争的生物学目标。AI 智能体可以自动化专家定义的分子设计流程，但仅靠自动化并不能解决如何为新任务优化工作流，或如何通过经验改进其开发过程的问题。在此，我们提出 MoLRSI，一种 AI 智能体，它将工作流和模型架构的系统性优化与持久的跨任务记忆相结合，以递归地改进其用于分子发现的搜索策略。工作流性能、细化结果和执行反馈指导后续搜索，使该智能体能够同时改进其工作流及其开发这些工作流的策略。我们在两个具有挑战性的分子发现场景中评估 MoLRSI，这些场景需要平衡相互竞争的性质。在抗生素发现中，MoLRSI 开发了一种筛选工作流，平衡抗菌活性、细胞毒性和结构新颖性，实验命中率达到 15.9%，而先前由专家主导的工作流在相同训练数据和筛选库下为 8.7%。在从头设计肽-MHC 结合物中，MoLRSI 开发的工作流同时考虑靶标结合和特异性，产生了八个针对 MART-1 和 SARS-CoV-1 pMHC 的实验验证命中物，并且相对于所测试的脱靶物具有优先结合，而 Claude Science 则完全失败。这些发现表明，经验引导的工作流优化可以解决相互竞争的发现目标，同时改进后续活动中使用的搜索策略。

## Abstract
Molecular discovery requires navigating vast combinatorial search spaces while balancing competing biological objectives. AI agents can automate expert-defined molecular design protocols, but automation alone does not address how to optimize workflows for new tasks or improve their development through experience. Here we introduce MoLRSI, an AI agent that combines systematic optimization of workflows and model architectures with persistent cross-task memory to recursively improve its search policy for molecular discovery. Workflow performance, refinement outcomes, and execution feedback guide subsequent searches, allowing the agent to improve both its workflows and its strategy for developing them. We evaluate MoLRSI in two challenging molecular discovery settings that require balancing competing properties. In antibiotic discovery, MoLRSI developed a screening workflow balancing antibacterial activity, cytotoxicity and structural novelty, achieving an experimental hit rate of 15.9%, compared with 8.7% for a previous expert-led workflow using the same training data and screening library. In de novo peptide-MHC binder design, MoLRSI developed workflows that jointly consider target binding and specificity, producing eight experimentally validated hits against MART-1 and SARS-CoV-1 pMHCs with preferential binding over tested off-targets while Claude Science completely failed. These findings demonstrate how experience-guided workflow optimization can address competing discovery objectives while improving the search strategies used in subsequent campaigns.

## 1. 核心问题与研究动机

- **背景**：分子发现（抗生素筛选、蛋白/多肽结合子设计）需要在巨大的组合空间中同时平衡活性、特异性、毒性、结构新颖性、稳定性等多个**相互竞争**的目标。传统上依赖专家设计"库准备—筛选—反筛—命中验证"流程，近年来计算工作流（表征、模型架构、训练目标、优化策略、评估准则的组合）成为主流。
- **核心痛点一**：给定任务寻找有效工作流本身是一个困难的搜索问题。可选组件（分子表征、GNN/Transformer/树模型、预训练策略、损失函数、集成方式、打分准则）组合爆炸，且最优配置随靶标、数据规模、目标性质而变。
- **核心痛点二**：现有科学智能体（Biomni、Claude Science、STELLA、Codex 等）能自动化"专家写好的协议"，但**自动化 ≠ 优化**。每次 campaign 相互孤立，一个项目中"哪种架构适合这类数据、哪种训练策略提升泛化、哪些工程约束必须处理"的经验无法迁移到下一个任务，导致重复试错。而每次候选评估都要付出昂贵的湿实验代价。
- **核心洞察**：人类科学家的搜索策略（policy）由跨项目经验塑造——成功与失败都会改变其起点选择与改进优先级，经验越多，试错越少。论文试图让 AI agent 具备同样的**递归自我改进（Recursive Self-Improvement, RSI）**能力：每个项目不仅产出一个工作流，还产出改进"未来如何开发工作流"的经验。
- **研究假设**：在经验引导下对模型与工作流进行系统优化，可以在竞争性目标约束下提升真实分子发现效果。

## 2. 方法论

### 2.1 总体框架
MolRSI = **工作流/模型架构的系统搜索** + **持久跨任务记忆**，二者耦合形成 RSI 闭环。每个任务由生物问题、可用数据、评估准则、计算预算四要素定义。

### 2.2 资源库构建（Explore Agent）
- 根据任务描述与数据特征生成检索 query，检索论文、代码仓库、工具、benchmark、算法。
- 将每个资源封装为**可复用 skill**：用途、依赖、输入输出、执行步骤、代码/文档引用。
- 构建期做语法、依赖、接口静态检查；**首次使用时在隔离环境跑通示例**，失败则依据报错修复代码/依赖/环境，通过者标记为 validated 并保留，多次修复仍失败者剔除。
- 规模：小分子库 **110 个技能**（55 模型 + 48 方法 + 7 工具/资源）；蛋白库 **65 个技能**（28 模型 + 37 注册打分项）。

### 2.3 三类持久记忆
| 记忆类型 | 存储内容 | 用途 |
|---|---|---|
| **Solution memory** | 工作流可执行代码、配置（组件、架构、超参、数据处理、训练/生成流程）、执行状态、development score 及其任务/数据集/指标/划分/种子上下文 | 家族选择、父代采样、零搜索迁移 |
| **Refinement memory** | 原工作流与修改后工作流、改动类型与理由、修改前后分数及差值；失败修改也保留 | 指导后续修改提案，避免重复无效改动 |
| **Execution memory** | 运行时长、GPU 时间、吞吐、显存、软硬件环境；失败阶段、报错日志、根因、修复尝试及是否成功 | 资源规划、错误复用修复 |

记忆在任务内迭代更新，并保留至后续任务；**held-out test 分数不进入记忆、不参与选择**。

### 2.4 经验引导的 MCTS（五步搜索）
以"工作流森林"表示：初始工作流为各树根，节点=具体工作流，父→子边=一次修改，按共同模型/方法划分**工作流家族**。

1. **选择家族**：UCB 式打分 = 当前任务最优 development score（exploit）+ 探索 bonus `α·sqrt(ln(b+1)/n_b(f))` + **历史迁移分 transfer(f)**。
2. **选择父代**：按 softmax 采样，权重 ≈ `σ(β·标准化当前分) × 1/(1+c_i) × (1+λ·transfer(v_i))`，其中 `c_i` 为已有子代数（抑制反复扩张同一父代）。
3. **提出修改**：从 refinement memory 检索相关任务的改动及结果，生成改动方案与理由；执行前做格式、去重、可行性检查。
4. **执行与评估**：依据 execution memory 配置资源；失败时优先检索相似错误的既往修复，否则现场诊断，受修复次数与预算上限约束；同一候选的修复不额外消耗评估配额。
5. **更新策略**：把工作流/分数、修改/结果、运行时/错误/修复分别写回三类记忆，改变后续迭代的家族选择、父代采样、修改提案与执行。

### 2.5 RSI 的形式化
- 历史分数**先定向再标准化**：`s = x`（越高越好）或 `−x`（越低越好）；`s̃ = (s − median)/max(MAD, ε)`；再经 `s̄ = 2σ(s̃) − 1 ∈ [−1,1]` 映射为有界效用，使不同量纲任务可聚合。
- **任务相似性权重**：`w(τ,τ0) = w_metric · w_type · w_size · w_emb`，其中 `w_size = exp(−γ|log|D_τ| − log|D_τ0||)`，`w_emb = max{cos(e_τ, e_τ0), 0}`。
- **迁移分**：家族级为按权重加权、先任务内平均再跨任务合并的效用均值；工作流级为按"家族 + 修改类型"匹配到的历史工作流的加权效用。
- **策略更新方程**：
  `π_t(a|s) = π(a|s; M_t)`，`M_{t+1} = Update(M_t, E_t)`，`π_{t+1}(a|s) = π(a|s; M_{t+1})`
  即"记忆改变策略 → 策略产生新经验 → 经验再改记忆"的递归闭环。
- **零搜索迁移（zero-search transfer）**：按任务类型、指标、数据规模、描述相似度匹配最佳源任务，直接取其在 solution memory 中的最优工作流，仅在新任务训练数据上重拟合参数，不再搜索。
